# Link’s Awakening for PS5 v0.1.0

## Features

- Native PS5 home-screen title PPSA99670.
- 1080p rendering with 4K FSR1-upscaled output.
- DualSense controls and PlayStation button prompts.
- Native audio and movie playback.
- Controller-operated launcher and touchpad settings menu.
- Background shader compilation and persistent shader caches.
- Separate application download and desktop game preparation.
- Licensed island artwork for the home icon and launch screen.

## Installation

Install PPSA99670.zip, then use the matching Linux setup bundle to prepare your
own Switch version 1.0.0 base-game NSP with your local keys. Copy the resulting
extracted folder into the installed title. Windows users can run setup in WSL2.
Preserve the title’s user folder when updating.

Game dumps, keys, generated game code and saves are not included.
