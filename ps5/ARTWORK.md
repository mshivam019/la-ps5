# Application artwork

The island emblem is **Island** by **Delapouite**, from
https://game-icons.net/1x1/delapouite/island.html, licensed under
[Creative Commons Attribution 3.0 Unported](https://creativecommons.org/licenses/by/3.0/).

The emblem is recolored and placed in original SVG layouts with DejaVu Sans
typography. Original vector source and editable layouts are in `ps5/art/`.
The home icon is 512×512; selection and launch backgrounds are 3840×2160 BC7 DDS.

Render with `python3 ps5/art/render.py` using `rsvg-convert`, DejaVu Sans, Pillow and `ispc_texcomp`.
This artwork contains no Nintendo promotional images or official Zelda logo.
The title identifies the compatible game; this is an unofficial port.
